PaStaCoin / prototype wallet

Prototype wallet

Move test coins between accounts on the PaSta prototype chain and watch the network confirm them.

Don't buy pastacoin. There is nothing to buy: this is a test chain, its coins have no value, and it can be reset at any time. It exists to try the idea out, not as an investment.

Connecting… Node:

No node is answering at that address. This wallet needs a PaSta node to talk to. The project's public node, https://seed.pastacoin.org, is the default: “Change node”, then “Use the default”, goes back to it. To run your own on this computer instead:

git clone https://github.com/pastacoin/pastacoin
cd pastacoin
pip install -e .
python node.py --storage chain.json

A new chain writes genesis-wallet.json next to the chain file. Import it here to hold the first 10 PASTA, and point this page at it with “Change node” (http://localhost:5000).

      The network

      Nobody is given coins except the 10 PASTA in the first block. Everything else is minted, or burned, by a rule that watches the size of a typical payment and nudges the supply so that size stays at its target.

      How a payment becomes final

      PaSta has no miners. The people making payments validate each other's:

      1. You send. Your wallet signs the payment and the node holds it as pending.
      2. You validate someone else's. To earn the right to be confirmed, your payment first confirms another waiting payment from a different sender. This page does that for you as soon as one is available.
      3. Someone else confirms yours. The next person to send or to press “Confirm” finalizes your payment and it joins the chain. Only then does the money move.

      So a quiet chain is a slow chain: if nobody else is around, your payment waits. To try it alone, make a second wallet and use “Confirm” from it. The rules are written down in the specification; what the stability rule can and cannot do is on the simulation results page.
