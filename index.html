PaStaCoin is a cryptocurrency project with the goal of passive stability, high throughput and minerless validation on a proof-of-work blockchain.

Open the wallet Download the desktop node (Windows)

A public test chain is running. The wallet works in your browser and keeps your keys there. The desktop node keeps its own copy of the chain on your computer and checks every block itself; it is built from source by GitHub (release notes and checksum), and Windows will warn that it is unsigned. The coins are test coins with no value, and the chain can be reset.

Simulation results View on GitHub

Does minting and burning against the average transaction size actually hold purchasing power? The simulation results page shows what worked, what broke, and what is still open. The Bitcoin demonstration and the multi-chain comparison check the fixed-supply argument against real chain data.
